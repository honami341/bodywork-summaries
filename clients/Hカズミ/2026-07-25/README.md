- 日付：2026-07-25

- 公開ページ：`public/advice/rotation-anchor-ribcage-2026-07-25/index.html`
- 公開タイトル：回転を止める体幹アンカーと、胸郭から腕を上げる

## 記録要点

- 回転の勢いで下半身まで流れ、狙った位置で止まりにくい。
- 肘と脇腹のつながりを「アンカー」として使い、腕が後方へ動いても体幹側に支点を残す。
- 胸骨・鎖骨・上部肋骨から肘までを一続きとして動かす。
- 腕を上げる初動は手ではなく、脇腹・肋骨の側屈と肩甲骨の上方移動。
- 自宅課題は、鴨居やドア枠を使い、胸郭を横と上へ開くストレッチ。
